# Comandos de Linux

Esta carpeta contiene ejemplos de comandos básicos de Linux utilizando Bash.

## Archivos disponibles

### `navegacion.sh`
Practica los siguientes comandos:

- `pwd`: muestra el directorio actual.
- `ls`: lista los archivos y carpetas.
- `ls -la`: muestra el contenido detallado, incluidos los archivos ocultos.

### `archivos.sh`
Practica los siguientes comandos:

- `mkdir -p`: crea una carpeta si no existe.
- `touch`: crea un archivo vacío.
- `ls -l`: muestra información de los archivos.
- `cat`: muestra el contenido de un archivo.

## Ejecución

Desde la raíz del repositorio:

```bash
bash comandos/navegacion.sh
bash comandos/archivos.sh
```

## Objetivo

Aprender a utilizar la terminal de Linux y automatizar tareas sencillas mediante scripts de Bash.
