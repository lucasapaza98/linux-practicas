# Ejercicios de Linux

Esta carpeta contiene actividades prácticas para aprender a utilizar la terminal de Linux.

## Ejercicio 1: información del sistema

Archivo: `ejercicio01.sh`

Comandos utilizados:

- `whoami`: muestra el usuario actual.
- `pwd`: muestra el directorio de trabajo.
- `date`: muestra la fecha y la hora.

## Ejercicio 2: estructura de carpetas

Archivo: `ejercicio02.sh`

Comandos utilizados:

- `mkdir -p`: crea directorios.
- `touch`: crea archivos vacíos.
- `ls -R`: muestra recursivamente el contenido de los directorios.

## Cómo ejecutar los ejercicios

Desde la raíz del repositorio:

```bash
bash ejercicios/ejercicio01.sh
bash ejercicios/ejercicio02.sh
```

## Objetivo

Practicar los comandos de Linux mediante actividades sencillas y progresivas.
