# Linux y Git: prácticas

Repositorio personal para aprender y practicar comandos de Linux, scripts de Bash y control de versiones con Git.

## Estructura del proyecto

### `comandos/`
Ejemplos de comandos básicos de Linux y scripts de Bash.

### `ejercicios/`
Actividades prácticas para reforzar los conocimientos adquiridos.

## Requisitos

- Linux o WSL.
- Bash.
- Git.

## Cómo ejecutar los ejemplos

Cloná el repositorio y entrá en su carpeta:

```bash
git clone URL_DEL_REPOSITORIO
cd linux-practicas
```

Ejecutá los scripts utilizando Bash:

```bash
bash comandos/navegacion.sh
bash ejercicios/ejercicio01.sh
```

Reemplazá `URL_DEL_REPOSITORIO` por la dirección real del repositorio.

## Objetivos de aprendizaje

- Conocer la terminal de Linux.
- Crear y administrar archivos y carpetas.
- Escribir scripts básicos de Bash.
- Aprender a utilizar Git y GitHub.
- Registrar cambios y documentar los proyectos.
